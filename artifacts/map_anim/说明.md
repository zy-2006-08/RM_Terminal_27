# 地图事件动画截图（第五块）

重拍：`bash scripts/shoot_effects.sh map_anim`，再 `python3 scripts/shot_sheet.py artifacts/map_anim/sheet-map.json` 出拼图。私有端口，不碰 3333。

- `changes-map.png`：六种动画拼在一张里。
- `part-*.png`：单块，文件名就是内容。
- `dart / gate / rune / base-hit / zone / fortress-1440x900.png`：整屏，各拍一种。

动画只放两三秒（堡垒被偷一直画到不偷了），所以每张都是在事件发生后不到一秒截的：

| 文件 | 模拟器里怎么触发 |
|---|---|
| dart | `blind 2 2`：红方飞镖打中蓝方基地固定目标 |
| gate | `dart-open 2`：蓝方开飞镖闸门 |
| rune | `enemy-rune small`：敌方开小能量机关 |
| base-hit | `structure 0 9200`：红方基地掉 800 血 |
| zone | `zone 1 2`：蓝方前哨阵地变成红方完全控制 |
| fortress | `fortress 1`：蓝方开始激活红方堡垒 |
